
# CLI Calculator 🧮

A command-line calculator built using Python as part of the Elevate Labs Python Development Internship.

The application performs basic arithmetic operations through an interactive terminal menu and continues running until the user chooses to exit.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Interactive command-line menu
- Input validation for invalid numbers
- Division-by-zero handling
- Continuous execution until exit

## Technologies Used

- Python 3
- VS Code
- Git and GitHub

## Getting Started

### Prerequisites

Make sure Python 3 is installed on your system.

Check your Python version:

```bash
python3 --version
```

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/elevate-labs-python-calculator.git
```

Navigate to the project directory:

```bash
cd elevate-labs-python-calculator
```

### Run the Application

Execute the following command:

```bash
python3 calculator.py
```

Follow the on-screen menu to select an operation, enter two numbers, and view the result.

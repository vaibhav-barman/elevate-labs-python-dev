## 📂 Tasks

### Task 1 — CLI Calculator

A command-line calculator that performs basic arithmetic operations.

**Features:**

* Addition, subtraction, multiplication, and division
* User input and operation selection
* Input validation and error handling
* Continuous calculations until the user chooses to exit
* Handling of division by zero

**Folder:** `Task-1-CLI-Calculator/`

* Use Git and GitHub for version control and project documentation.
* Develop command-line applications.
